[Heading1] 4. SEO Keyword Rules
[ListBullet] Primary keyword is mapped to one page only wherever possible to avoid keyword cannibalization.
[ListBullet] Primary keyword is intended to be used as the exact-match URL and H1 for its page.
[ListBullet] Secondary keywords are used within page content and are not added to the URL.
[ListBullet] Do not create a separate Field Service Management page; Field Service Management is covered on the Home page.
[ListBullet] Do not create Guides or Free Templates pages.
[ListBullet] Do not create Settings as a public SEO feature page.
[ListBullet] Do not pad keyword lists with zero-volume keywords.
[ListBullet] Keyword metrics already researched are based on Ubersuggest India data; additional unverified secondary terms are marked by the document structure but should be live-verified before final SEO targeting.

[Heading1] 7. Primary Keyword — Must-Use SEO Locations
Each page's primary keyword should be used naturally in the following important SEO locations. Exact wording should be preserved where practical, without keyword stuffing.
1. URL / Slug — MUST
[ListBullet] Use the primary keyword in the page URL/slug where the approved URL structure allows it.
2. H1 — MUST
[ListBullet] Use the primary keyword as the main H1, preferably as an exact match.
3. SEO Title / Meta Title — MUST
[ListBullet] Include the primary keyword, preferably near the beginning when it reads naturally.
4. Meta Description — MUST
[ListBullet] Include the primary keyword naturally and write a compelling description for search users.
5. Opening Content — MUST
[ListBullet] Use the primary keyword naturally within the first section/introductory paragraph.
6. One H2 Heading — Recommended
[ListBullet] Use the primary keyword or a close natural variation in an important H2 when it fits the page.
7. Image ALT Text — Recommended
[ListBullet] Use the primary keyword only where the image genuinely describes that topic; do not force it into every image.
8. Internal Links — MUST
[ListBullet] Use relevant internal links pointing to the page. Anchor text can use the primary keyword or a natural variation where appropriate.
9. Body Content — MUST
[ListBullet] Use the primary keyword naturally throughout the page where relevant; avoid repetitive keyword stuffing.
10. Schema / Structured Data — Recommended
[ListBullet] Where applicable, keep the page/topic and relevant name fields aligned with the page's primary topic/keyword.
[Heading1] 8. Primary Keyword Implementation Rules
[ListBullet] One primary keyword = one main target page.
[ListBullet] Do not use another page's primary keyword as the main target for this page.
[ListBullet] Keep the exact primary keyword in the URL and H1 as already approved in this document.
[ListBullet] Use secondary keywords in supporting headings and body content where they genuinely fit.
[ListBullet] Do not repeat the primary keyword unnaturally just to increase keyword density.
[ListBullet] Do not add the primary keyword to every image ALT, every heading, or every link.
[ListBullet] Write for users first; keyword placement should remain natural and relevant.
[ListBullet] For legal pages such as Privacy Policy and Terms & Conditions, do not force commercial SEO keywords.
